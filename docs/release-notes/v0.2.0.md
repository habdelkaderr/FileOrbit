## What's new

- **Image editing:** resize (by longest side, width, height, percentage or exact size), crop to an aspect ratio, rotate and flip, trim borders, black and white or sepia, auto-enhance, and compress to a target file size.
- **Background removal:** cut out the main subject of a photo with a small AI model that runs on your PC. No internet needed.
- **Update notices:** FileOrbit checks GitHub once a day and tells you when a new version is out. You can also click *Settings > Check for updates*. It never downloads or installs anything by itself.
- **New look:** an Apple-style design for the main window and the conversion card, in light and dark. The radial menu is unchanged.
- **Much lighter:** while waiting in the notification area FileOrbit now uses a few MB of memory instead of about 150 MB.
- **USB sharing:** run FileOrbit from a USB drive and it offers to install itself on that PC.
- **Fewer Windows Security warnings:** the optional Ghostscript add-on is only loaded when Ghostscript is installed.
